# 给你的一封生日来信

温暖纸感的生日解谜网站。纯 HTML / CSS / JavaScript，无后端、无需构建、无第三方网络依赖，支持手机和电脑。

## 试玩

下载后直接打开 `index.html`。开场 → 记忆题 → 图片题 → 字母密码 → 选择题 → 生日信与照片墙。每关有提示，答错可以重试；通过后点击按钮进入下一关。进度保存在当前浏览器，底部“重新开启”可重置；浏览器禁用存储时仍可完整游玩。

占位答案依次为 **0601、317、HAPPY、D（以上全部）**。英文忽略大小写，输入会自动兼容全角字符和空格。所有占位题目、姓名和素材均明确标注。

## 修改内容

打开 `config.js`，集中修改：

| 内容 | 配置 |
| --- | --- |
| 寿星与署名 | `recipient`、`sender`，以及 `letter` 中的姓名占位文字 |
| 开场文案 | `intro` |
| 题目、说明、提示 | `levels` 中的 `question`、`detail`、`hint` |
| 输入题答案 | `answers` 数组，可接受多个答案，例如 `['0601', '6月1日']` |
| 输入框占位文案 | `placeholder` |
| 选择题 | `options`；`correctIndex` 从 0 起，3 代表第四项 |
| 最终信件 | `letter` 数组，每个字符串是一段 |
| 版本 | 改题后更新 `version`，避免沿用旧进度 |

修改内容时保留 JavaScript 引号、逗号与括号；文字内的单引号应写成 `\'`。

## 图片

`assets/clue-1.svg` 至 `clue-3.svg` 是自制线索插画，数字从左到右为 3、1、7。替换时将照片放进 `assets/`，在第二关的 `images` 中修改 `src`、`alt` 与 `caption`，并同步修改答案和提示。`alt` 应描述图片线索，让读屏用户也能解题。

照片墙在 `photos` 中配置；默认使用 `assets/memory-1.svg` 至 `memory-3.svg`。可以替换为 `assets/your-photo.jpg`，也可以增加照片。图片推荐压缩至 500KB 左右，使用英文文件名和相对路径，不要以 `/` 开头，以兼容 GitHub Pages 子路径。图片加载失败时会保留文字描述。

## 音乐

把有权使用的音频放到 `assets/music.mp3`，将 `music: ''` 改成 `music: 'assets/music.mp3'`。音乐需要访客点击右上角按钮播放，避免手机浏览器的自动播放限制。默认不提供音频，不会请求不存在的音乐文件。

## GitHub Pages 发布

1. 在 GitHub 新建公开仓库 `birthday-puzzle-surprise`（重名时可加后缀）。
2. 将此文件夹**里面的文件**上传至仓库根目录，确保 `index.html` 位于根目录。
3. 打开仓库 **Settings → Pages → Build and deployment → Deploy from a branch**，选择 **main / (root)** 并保存。
4. 等待 Pages 部署成功，地址通常为 `https://你的用户名.github.io/仓库名/`。以 Pages 设置中显示的地址为准。

附带 `.nojekyll`，无需安装依赖或配置 Actions。后续在 GitHub 编辑配置或上传图片并提交，Pages 会自动重新发布。首次分享前在手机浏览器完整通关一次。

## 设计与兼容

使用系统字体和本地 SVG 素材；响应式布局、键盘可操作、读屏状态提示，尊重系统减少动态效果设置。彩纸效果持续约 6.5 秒，可再次触发。音乐不自动播放；无跟踪和分析服务。

这是生日小游戏，答案位于客户端源码，不用于保密。公开仓库与 Pages 中的照片、信件都可能被他人访问，请仅放置适合公开的内容。
